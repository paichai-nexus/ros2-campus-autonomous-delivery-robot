ROS2-based autonomous delivery robot research project for steep and pedestrian-dense campus environments.

This project investigates localization, path planning, obstacle avoidance, sensor fusion, and fail-safe control for low-speed autonomous mobility in the Paichai University campus environment.

## Research Question

How can a low-speed autonomous mobile robot maintain safe and reliable navigation in a steep campus environment with mixed pedestrian and vehicle traffic?

## Research Scope

### Phase 1 — Simulation and Baseline

- ROS2 / Nav2 development environment
- Gazebo-based simulation
- Baseline localization and navigation
- Static and dynamic obstacle handling
- Path-planning performance evaluation

### Phase 2 — Restricted-Area Validation

- Low-speed autonomous cart or delivery robot
- Campus slope navigation
- Pedestrian interaction scenarios
- Localization validation
- Emergency-stop and fail-safe validation
- Obstacle-based route replanning

### Phase 3 — Campus Mobility PoC

- Autonomous delivery mission execution
- Campus map integration
- Operational monitoring
- Campus mobility service integration study
